# North Sámi TeX hyphenation

This repository contains TeX hyphenation patterns for North Sámi and some of the files used to generate these.

The patterns and files are generated using data from [corpus-sme](https://github.com/giellalt/corpus-sme) and Finite State Transducer (FST) models from the GPL3 licensed [lang-sme](https://github.com/giellalt/lang-sme).

The hyphenation patterns provided here are based on the hyphenation FST in lang-sme (`tools/hyphenators/hyphenator-gt-desc.hfstol`). They differ mainly in requiring hyphenation minimum and maximum values of 2, whereas the FST also applies hyphenation after a single character. The Norwegian Sámi Parlament however [recommends](https://sametinget.no/sprak/nyttige-ressurser/riektacallinravvagat/) that words not be hyphenated after a single vowel, which implies a left hyphenation minimum of 2.

## Preprocessing procedure

The words lists used as input for the FST hyphenator come from two sources in an attempt to see what works best.

One source is the corpus-sme repository, from which North Sámi text has been fetched using the [CorpusTools](https://divvun.github.io/CorpusTools/) `ccat -l sme` command. The output has been filtered to only include normative forms and no words containing digits.

The other source is the lemma lists of lang-sme, from which full form lists have been generated by concatenating strings from a paradigm file and generating forms using the lang-sme normative generator (`src/fst/generator-gt-norm.hfstol`). Also here words containing digits have been filtered out.

The word lists have been hyphenated using the FST hyphenator of lang-sme. To compile this, the lang-sme configuration  `./configure --enable-fst-hyphenator` was used. The circumflexes and pound signs output by the hyphenator have been converted to hyphens for patgen use, and hyphens in the second or second-to-last position have been removed. The resulting file is used as the input dictionary file of patgen (`sme.dic`).

Here is a sample pipeline:
```
cat norm-corpus-uniq.txt | hfst-lookup lang-sme/tools/hyphenators/hyphenator-gt-desc.hfstol -q --beam 0| cut -f2|sort -u > hyphenated-words.txt
```
Note that beam is set to 0 to only return the best possible hyphenation of each word.

## Patgen generating procedure

As per the `patgen` [documentation](https://tug.ctan.org/info/patgen2-tutorial/patgen2-tutorial.pdf), generate patterns using the command `patgen sme.dic sme.pat sme.out sme.tra`, where:
- `sme.dic` is a list of hyphenated words
- `sme.pat` is a pre-existing pattern file, or an empty file
- `sme.out` is the output of the program
- `sme.tra` is a translate file containing configuration and the alphabet used

`sme.tra` specifies left and right hyphen min values (per now 2), in addition to defining the alphabet.

The patgen program asks for input, a suggestion would be:

hyph_start, hyph_finish: 1 9

pat_start, pat_finish: 1 15

good weight, bad weight, threshold: 1 1 1
