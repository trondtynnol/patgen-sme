The files are generated using data from [corpus-sme](https://github.com/giellalt/corpus-sme) and models from [lang-sme](https://github.com/giellalt/lang-sme)

As per the `patgen` [documentation](https://tug.ctan.org/info/patgen2-tutorial/patgen2-tutorial.pdf), generate patterns using the command `patgen sme.dic sme.pat sme.out sme.tra`, where:
- `sme.dic` is a list of hyphenated words
- `sme.pat` is a pre-existing pattern file, or an empty file
- `sme.out` is the output of the program
- `sme.tra` is a translate file containing configuration and the alphabet used

The list of hyphenated words is generated by making a list of unique word forms that are accepted by the norm analyser and then piping it through a hyphenator lookup with beam set to 0. 
```
cat norm-corpus-uniq.txt | hfst-lookup lang-sme/tools/hyphenators/hyphenator-gt-desc.hfstol -q --beam 0| cut -f2|sort -u > hyphenated-words.txt
```
This is further adapted to `sme.dic` by replacing circumflexes `^` and pound signs `#` with hyphens `-`.

`sme.tra` specifies left and right hyphen min values (per now 2), in addition to defining the alphabet.

The patgen program asks for input, a suggestion would be:
hyph_start, hyph_finish: 1 9
pat_start, pat_finish: 1 15
good weight, bad weight, threshold: 1 1 1
